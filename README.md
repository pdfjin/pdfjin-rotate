# 📄 pdfjin-rotate

> Rotate PDF pages by 90, 180, or 270 degrees by PDFJin by [PDFJin](https://pdfjin.com).

[![PyPI version](https://img.shields.io/pypi/v/pdfjin-rotate.svg)](https://pypi.org/project/pdfjin-rotate/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![Python 3.8+](https://img.shields.io/badge/python-3.8+-blue.svg)](https://www.python.org/downloads/)

Fast, private, and local document processing with zero size limits.

> 🌐 **Prefer a Web UI?** Use the free online browser tool at **[https://pdfjin.com/pages/rotate-pdf.html](https://pdfjin.com/pages/rotate-pdf.html)**.

---

## 📦 Installation

```bash
pip install pdfjin-rotate
```

Or install from source:

```bash
git clone https://github.com/pdfjin/pdfjin-rotate.git
cd pdfjin-rotate
pip install .
```

---

## 🚀 Quickstart

Run via CLI:
```bash
pdfjin-rotate --help
```

Use in Python:
```python
import pdfjin_rotate
```

---

## 🧪 Testing

```bash
pip install pytest
```
